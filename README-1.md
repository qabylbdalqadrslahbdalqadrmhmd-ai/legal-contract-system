# ⚖️ محلل العقود الذكي

تطبيق تحليل عقود احترافي مدعوم بالذكاء الاصطناعي (Claude من Anthropic)

## 🚀 المميزات

- **تحليل شامل** — نقاط القوة، الضعف، المخاطر، البنود الناقصة
- **تقييم بالنقاط** — وضوح، اكتمال، حماية قانونية، توازن
- **إنشاء عقود** — صياغة عقود احترافية من الصفر
- **دعم كامل للعربية** — واجهة وتحليل بالعربية
- **صيغ متعددة** — PDF, Word, صورة, نص مباشر

## 📦 التثبيت

```bash
pip install -r requirements.txt
```

## ⚙️ الإعداد على Streamlit Cloud

1. ارفع الملفات على GitHub
2. اذهب إلى [share.streamlit.io](https://share.streamlit.io)
3. اربط الـ repo
4. في **Secrets** أضف:
```toml
ANTHROPIC_API_KEY = "sk-ant-..."
```

## 🏃 التشغيل المحلي

```bash
streamlit run app.py
```
